> [!answer]- 派生自查口径（首答后展开）
> 核心机制：缩短 CPU 执行时间的影响因素；平均 CPI、总时钟周期数、CPU 执行时间计算
>
> 达标标准：
> - CO_2010_001 知识点：CO01-14 CPU 执行时间
> - CO_2010_001 安全摘要：围绕程序执行时间的影响因素做概念辨析，要求判断哪些硬件或软件层面的改变会缩短 CPU 执行时间。
> - CO_2010_001 关键参数核验：复做时先使用 `CPU时间 = 指令数 x CPI x 时钟周期 = 指令数 x CPI / 主频`；逐项判断主频/时钟周期、数据通路结构、编译优化分别影响公式中的哪一部分。
> - CO_2010_001 错误入口核验：知道优化数据通路结构和编译优化会缩短执行时间，但遗漏提高 CPU 时钟频率会缩短时钟周期，从而缩短 CPU 执行时间。
> - CO_2010_001 第一动作核验：先写 CPU 执行时间公式，再把每个措施映射到指令数、CPI、时钟周期或主频，不凭直觉判断。
> - CO_2010_001 机制边界：缩短 CPU 执行时间的影响因素
> - CO_2022_003 知识点：CO01-14 CPU 执行时间
> - CO_2022_003 安全摘要：给定指令类型比例、CPI 和主频等性能参数，先求平均 CPI 与总时钟周期数，再换算 CPU 执行时间。
> - CO_2022_003 关键参数核验：各类指令比例、各类 CPI、指令总数、主频或时钟周期；时间单位可能跨 ns、us、ms，需要先统一数量级。
> - CO_2022_003 错误入口核验：平均 CPI 计算已能理解，但执行时间单位换算时曾把不同时间单位数量级混淆。
> - CO_2022_003 第一动作核验：先写 `CPU 时间 = 指令条数 * 平均 CPI / 主频`，再单独写单位换算等式，最后代入。
> - CO_2022_003 机制边界：平均 CPI、总时钟周期数、CPU 执行时间计算
