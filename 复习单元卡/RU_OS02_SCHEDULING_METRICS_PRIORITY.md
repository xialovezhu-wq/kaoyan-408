# RU_OS02_SCHEDULING_METRICS_PRIORITY · 调度评价指标与优先级设计原则

## 闭卷提取

闭卷把吞吐量、周转时间、响应时间、CPU 利用率、公平性、互斥性分成调度指标与非调度属性；再为 I/O 密集和 CPU 密集进程设计优先级并说明理由。

先独立作答并记录置信度、反应时与是否使用提示，再展开下方自查口径。

> [!answer]- 派生自查口径（首答后展开）
> 核心机制：调度指标描述系统或作业表现；优先级设计应结合 CPU/I/O 特性和系统目标，不是单纯按执行时长排序。
>
> 达标标准：
> - 互斥性不是调度评价指标
> - 响应时间与周转时间口径要分开
> - 优先级设计需服务 CPU 与 I/O 重叠或交互目标
> - 不能只看 CPU 长度
> - 仅在首次闭卷作答后显示核验口径；必须给出第一动作、关键中间状态/单位和边界解释，不能只报结论；多源单元需随机抽取至少两个变式方向。
> - 缺任一关键步骤时先给最小纠偏；3-5 分钟后无提示二次提取。反馈不展示原题答案、选项或既往错选。
