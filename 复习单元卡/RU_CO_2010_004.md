> - CO_2010_004 关键参数核验：讨论对象是同时具有 TLB 和 Cache 的虚拟存储系统；Page 表示虚拟页面是否已经在主存中，不是页表本身；TLB 缓存有效页表项，Cache 缓存主存数据块副本；本题考命中状态之间的逻辑蕴含关系。
> - CO_2010_004 错误入口核验：2026-07-05 入库：最初不知道 Page 的含义，把 Page 误理解成虚拟页表或查表工具，并把 TLB 与 Cache 都笼统理解成“快表/缓存”；未先区分 Page 是被管理的页面本身、TLB 是页表项缓存、Cache 是主存数据块缓存，导致无法判断 TLB 命中、Cache 命中与 Page 命中之间的推出关系。
> - CO_2010_004 第一动作核验：先把三者角色分开：Page 是页面是否在主存，TLB 缓存页表项，Cache 缓存主存块副本；再判断蕴含关系：TLB 命中或 Cache 命中都说明 Page 在主存，Page 命中则不保证 TLB/Cache 命中。
> - CO_2010_004 机制边界：同时具有 TLB 和 Cache 的虚拟存储系统中，TLB 命中和 Cache 命中都能推出 Page 命中，但 Page 命中不能反推出 TLB 或 Cache 一定命中
