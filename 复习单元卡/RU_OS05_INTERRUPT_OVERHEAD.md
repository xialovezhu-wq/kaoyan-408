# RU_OS05_INTERRUPT_OVERHEAD · 中断 I/O 的 CPU 占用率

- 覆盖正式节点：OS_UNK_088
- 旧复习单元：无
- 当前状态：uncalibrated_baseline_due

## 闭卷提取

闭卷给定设备数据率、每次中断搬运量、单次服务时间和 CPU 周期，依次算中断频率、每秒中断开销和 CPU 占用比例，检查单位。

先独立作答并记录置信度、反应时与是否使用提示，再展开下方自查口径。

> [!answer]- 派生自查口径（首答后展开）
> 核心机制：单位时间中断次数由设备数据率和每次服务数据量决定，再乘单次中断服务时间得到 CPU 占用。
>
> 达标标准：
> - 中断次数=单位时间数据量/每次服务量
> - 总开销=次数×单次开销
> - 占用率需统一为同一时间单位
> - 不能把设备传输时间全部算成 CPU 忙碌
> - 仅在首次闭卷作答后显示核验口径；必须给出第一动作、关键中间状态/单位和边界解释，不能只报结论；多源单元需随机抽取至少两个变式方向。
> - 缺任一关键步骤时先给最小纠偏；3-5 分钟后无提示二次提取。反馈不展示原题答案、选项或既往错选。
