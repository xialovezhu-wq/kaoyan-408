## 二、核心思想

- 排序辨析先分两大类：比较类（插入 / 交换 / 选择 / 归并）vs 分配收集类（基数）。基数排序不比较大小，能突破 O(nlogn) 比较下界。
- 稳定性总表：稳定 = 直接插入、折半插入、冒泡、二路归并、基数；不稳定 = 希尔、快速、堆。稳定性看"相等关键字相对顺序是否不变"，不是看位置是否移动。
- 与初始状态的关系：比较类的比较 / 移动次数随初态（有序 / 逆序 / 随机）变化；基数排序按位搬 n×d 次，移动次数与初态无关。快排的递归次数 / 深度取决于划分平衡性，有序 / 逆序 + 首元素 pivot 会退化。
- 移动次数 vs 比较次数要分开：简单选择排序比较次数固定 n(n-1)/2，但移动 / 交换次数仍与初态有关。
- 堆排序：升序用大根堆；先 O(n) 建堆（从 ⌊n/2⌋ 起向前"向下调整 / 下滤"），每趟堆顶与无序区末尾交换后再对剩余区下滤，总 O(nlogn)；建堆 / 删堆顶都向下沉，只有插入才向上浮。
- 存储结构适配：链式存储不支持随机访问，但支持顺链扫描。直接插入 / 简单选择 / 冒泡仍可顺序扫描完成；希尔排序依赖增量跳跃访问，堆排序依赖顺序表父子下标关系，改链式存储时效率边界要单独判断。
- 快排 vs 归并：快排选 pivot 分区递归（一趟后 pivot 归位、左右内部不一定有序）；归并段长 1 两两合并、段长翻倍。判中间序列看结构——快排找"左小右大支点"，归并找"等长 (2^k) 有序块"。
- 基数排序：从最低位 LSD 起（谁最后排谁主导 → 最高位必须最后排）；O(d(n+r))，d 位数、r 基数；桶 = FIFO 队列保证稳定；空间 O(r)。
- 外部排序：置换-选择造更长初始段（≈2 倍工作区）→ 最佳归并树（哈夫曼思想给不等长段定归并次序）→ 败者树 k 路选最小；趟数 S=⌈log_k m⌉，m↑趟↑、k↑趟↓；补虚段先看 (n−1) mod (k−1) 是否为 0。
- 应用选择：小而基本有序 → 直接插入；大而平均快、可接受不稳定 → 快排；要最坏 O(nlogn) → 堆；要稳定且容许 O(n) 空间 → 归并；关键字位数少 → 基数。

## 三、典型错因

- 把"移动次数 / 比较次数与初始状态的关系"搞反：误以为直接插入移动次数与初态无关（实际随初态变），漏掉基数排序才是"移动次数与初态无关"。
- 把"比较次数固定"误当成"移动次数与初态无关"（简单选择排序的陷阱）。
- 误判基数排序不稳定、误以为每位内部仍靠比较、误以为受 O(nlogn) 下界限制。
- 基数排序误以为 MSD / LSD 逻辑一样，从最高位起导致低位排序冲掉高位顺序。
- 堆排序：建堆方向说成"向上调整"（应向下调整 / 下滤）、建堆复杂度说成 O(logn)（应 O(n)）、把每趟调整说成"重建堆"、混入堆插入的上浮过程。
- 把快排"分区递归"和归并"分段合并"流程混；以为一趟后左右区间内部已有序。
- 把"链式存储不能随机访问"泛化成所有排序效率都会下降，未区分顺序扫描型排序和强依赖下标跳转的排序。
- 快排递归次数误判为"与初始排列无关"（实际取决于划分平衡性）。
- 排序算法选型只记平均时间，漏看基本有序、小规模、稳定性、严格辅助空间等限制；尤其把快速排序递归栈空间漏掉，或把一趟划分 O(n) 误当整体 O(n)。
- 外部排序把"初始段数 m 越多"误判为"趟数越少"；补虚段时把余数当补段数、或在 u=0 时机械套 (k−1)−0。
- 排序稳定性把"位置是否变化"当判据，而不是看相等关键字相对顺序。

## 四、错题节点

### 1. 排序性质辨析

- DS_2015_005：哪种排序的元素移动次数与关键字初始状态无关（基数排序）；重点分清比较类受初态影响 vs 分配收集类流程固定。
- DS_2009_003：给"第二趟排序后结果"判断只能是哪种排序——直接插入前缀有序、二路归并按固定长度 2^k 切段且段内有序、冒泡后 k 个全局最大、简单选择前 k 个全局最小；本序列首段 {11,12,13,7} 无序排除归并、前缀 {11,12,13} 有序故为插入。
- DS_2010_003：快速排序递归次数取决于划分平衡性、受初始排列与 pivot 选择影响，与分区处理顺序无关；pivot 归位 ≠ 递归次数固定。
- DS_2017_004：顺序存储改为链式存储后，按"是否强依赖随机访问/下标跳转"判断排序时间效率是否降低；直接插入、简单选择、冒泡属于顺序扫描型，希尔和堆排序依赖下标访问特征。
- DS_2022_002：直接插入排序与快速排序适用场景比较——基本有序、小规模、稳定性、严格辅助空间条件下倾向直接插入；快速排序平均快但不稳定，递归栈非严格 O(1)，固定枢轴遇基本有序可能退化。

### 2. 排序过程模拟

- DS_2018_002：建大根堆从 ⌊n/2⌋ 起向前向下筛选（下滤）；交换后被换下结点若仍破坏堆序要继续下滤，不是让换上来的元素向上冒。

### 3. 堆操作基础（堆排序的支撑，主知识点为 DS05-22 堆）

- DS_2009_002：小根堆插入——新元素放末尾保持完全二叉树形状，再与父 ⌊i/2⌋ 比较、小者上浮（上滤）。
- DS_2015_004：小根堆删除堆顶——末尾补根 + 向下调整；下滤先比较两个孩子选较小者（这步也计比较）。
