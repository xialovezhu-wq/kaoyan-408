# 历史错题定位规则

本文件规定历史归档题的“定位信息”怎么理解、怎么检索、怎么输出。

历史归档题已经映射到统一正式错题库。历史归档题的核心作用是：作为来源 ID 和定位入口，让用户能快速回到原资料中找到这道题。

---

## 一、定位信息分层

历史题至少有四层定位信息，输出时不能混用。

### 1. 历史归档 ID

格式示例：

- `HDS_0002`
- `HCO_0022`
- `HOS_0142`
- `HCN_0065`

用途：

- 作为来源 ID，用于本 Markdown 仓库内部检索和原资料定位。
- 说明该正式节点来自历史归档题。
- 不等于正式错题节点 ID。
- 不能作为 `关系边表.md` 的起点或终点；关系边统一使用正式节点 ID。

### 2. 年份

格式示例：

- `2016`
- `2020`
- `未标明`

用途：

- 用于真题年份复盘。
- 年份不是原资料内部定位标记。
- 只有“2016年真题”但没有章节题号时，定位标记仍然写“未提取”。

### 3. 定位标记

定位标记指原资料内部的章节题号、题组号或笔记定位号。

有效示例：

- `5.1.4（06）`
- `3.2.11（54）`
- `2.3.33`
- `5.4.4 (08)`
- `7.2.5 （14）`

用途：

- 这是用户去原资料或笔记软件中找题时最重要的标记。
- 如果一条记录命中多个定位标记，保留多个，用 `；` 分隔。

### 4. 段落号与完整来源位置

格式示例：

- `段落2994`
- `408 / 计算机组成原理 / 2.计算机组成原理 / 第五章 中央处理器 / CPU的功能和基本结构结构 / 5.1.4（06） / n位CPU含义 / 段落2994`

用途：

- 当定位标记缺失或不够精确时，用段落号和完整来源位置兜底。
- 完整来源位置必须尽量原样保留，方便用户回到原整理包或笔记结构中查找。

---

## 二、什么算定位标记

以下内容算定位标记：

- 带括号题号的章节标记：`5.1.4（06）`、`3.2.11（54）`
- 不带括号但明显是章节题号的标记：`2.3.33`、`4.2.22`
- 半角括号、全角括号、括号前有空格的同类形式：`5.4.4 (08)`、`7.2.5 （14）`

定位标记也要区分强弱：

- 强定位标记：带题号括号的形式，例如 `5.1.4（06）`。这类最优先输出。
- 辅助定位标记：不带括号的三段式编号，例如 `2.3.33`。如果它在原资料中明显指向题号，可以作为定位标记；如果只是章节名，则只能辅助缩小范围。
- 如果一条记录同时有强定位标记和辅助定位标记，两个都保留，但复做时优先使用强定位标记。

以下内容不算定位标记：

- 整理日期：`2026.4.18`、`2026.4.1`
- 真题年份：`2016年真题`、`2020年统考真题`
- 知识点编号：`CO03-14`、`OS03-30`
- 历史归档 ID：`HCO_0022`
- 正式错题节点 ID：`CO_2022_006`

---

## 三、查找优先级

给用户找历史题时，按这个顺序定位：

1. 先用定位标记找原题，例如 `5.1.4（06）`。
2. 如果定位标记缺失或不够明确，再用段落号，例如 `段落2994`。
3. 如果仍然不够明确，再用完整来源位置。
4. 历史归档 ID 只用于在本仓库里二次检索，不作为用户找原题的唯一依据。

---

## 四、输出格式

每次输出历史归档题时，必须用下面字段。

```text
历史归档ID：
年份：
定位标记：
段落号：
核心考点：
完整来源位置：
```

如果定位标记没有提取到，必须写：

```text
定位标记：未提取
```

但仍然必须输出：

- 段落号
- 完整来源位置

---

## 五、示例

### 有定位标记

```text
历史归档ID：HCO_0022
年份：未标明
定位标记：5.1.4（06）
段落号：段落2994
核心考点：n位CPU含义
完整来源位置：408 / 计算机组成原理 / 2.计算机组成原理 / 第五章 中央处理器 / CPU的功能和基本结构结构 / 5.1.4（06） / n位CPU含义 / 段落2994
```

### 没有定位标记

```text
历史归档ID：HCO_0001
年份：未标明
定位标记：未提取
段落号：段落2514
核心考点：Cache 系统失效时的数据传送粒度
完整来源位置：408 / 计算机组成原理 / 2.计算机组成原理 / 第三章 存储系统 / Cache-写策略 / Cache 系统失效时的数据传送粒度 / 段落2514
```

---

## 六、禁止混淆

- 不要把 `2026.4.18` 当成定位标记；这是整理日期。
- 不要只输出“2016年真题”；年份不够用户回到原资料找题。
- 不要只输出 `HCO_0022`；历史归档 ID 只能作为来源 ID 和定位入口。
- 不要用历史归档 ID 建立正式关系边；必须先查 `正式ID映射.md`，用正式节点 ID 建边。
- 不要为了补全定位标记而编造原资料中没有的题号。
