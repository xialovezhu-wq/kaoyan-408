## 数据结构

### KP_0001 数据结构三要素

- 来源位置：数据结构 / 第一章 绪论 / 数据结构三要素
- 模块：绪论
- 核心内容：逻辑结构、存储结构、运算定义/实现要分开；算法复杂度关注规模增长阶。
- 易混点：把逻辑结构与存储结构混为一谈；把操作定义当成实现。
- 典型错因：只背结论，遇到题干关键词“顺序/链式/有序”时不能落到成本分析。
- 可关联专题链：LINK06 分层结构专题链
- 适合关联的错题类型：数据结构基础选择题；复杂度判断题
- 信息缺口：无明显缺口

### KP_0002 顺序表随机访问与插删搬移

- 来源位置：数据结构 / 第二章线性表 / 顺序表
- 模块：线性表
- 核心内容：顺序表连续存储，按位访问 O(1)；插入/删除平均 O(n)，有序只改善查找位置，不消除搬移。
- 易混点：按值查找、按位访问、插入位置查找、完成插入整体复杂度。
- 典型错因：把“有序可折半”误当成所有操作都变快。
- 可关联专题链：LINK06 分层结构专题链
- 适合关联的错题类型：线性表复杂度选择题；顺序表算法题
- 信息缺口：无明显缺口

### KP_0003 链表地址与 next 语义

- 来源位置：数据结构 / 第二章线性表 / 链表
- 模块：线性表
- 核心内容：链表逻辑顺序由 next 域决定，不由结点物理地址大小决定；已知结点插删可 O(1)。
- 易混点：结点地址、链接地址、首元结点、头结点。
- 典型错因：把结点自己的地址当作 next 域内容。
- 可关联专题链：LINK07 状态变化专题链
- 适合关联的错题类型：单链表插入/删除指针题
- 信息缺口：无明显缺口

### KP_0004 循环队列指针约定

- 来源位置：数据结构 / 第三章 栈、队列和数组 / 队列
- 模块：栈、队列和数组
- 核心内容：循环队列判空/判满取决于 front/rear 定义；保留一个空位时常见队满为 (rear+1)%M==front。
- 易混点：rear 指向队尾元素还是队尾后一位置；初始值与第一次入队位置。
- 典型错因：不先确认指针语义，机械套用 front==rear。
- 可关联专题链：LINK07 状态变化专题链
- 适合关联的错题类型：循环队列状态判断题
- 信息缺口：无明显缺口

### KP_0005 压缩存储下标映射

- 来源位置：数据结构 / 第三章 栈、队列和数组 / 特殊矩阵
- 模块：数组与特殊矩阵
- 核心内容：对称矩阵先利用对称性映射到存储三角，再按行/列优先计算一维下标。
- 易混点：上三角/下三角、按行优先/按列优先、0 基/1 基下标。
- 典型错因：没有先完成对称映射，直接用原下标套公式。
- 可关联专题链：LINK01 地址划分专题链

### KP_0006 树森林与二叉树转换

- 来源位置：数据结构 / 第五章 树与二叉树
- 模块：树与二叉树

### KP_0007 图算法状态维护

- 来源位置：数据结构 / 第六章 图
- 模块：图
- 核心内容：BFS/DFS/拓扑/Dijkstra 都依赖集合、入度、dist、prev 等状态表逐步更新。
- 易混点：最短边贪心与 Dijkstra 松弛；拓扑序列与入度变化。
- 典型错因：跳过状态更新，只凭局部最小边或直觉选路。

### KP_0008 散列表查找效率

- 来源位置：数据结构 / 第七章 查找
- 模块：查找
- 核心内容：散列表效率受散列函数、装填因子、冲突处理与聚集影响；堆积直接影响平均查找长度。
- 易混点：装填因子变大不等于效率变高；堆积不是散列函数本身。
- 典型错因：只记“哈希 O(1)”而忽略冲突与平均查找长度。
- 可关联专题链：LINK07 状态变化专题链

## 操作系统

### KP_0019 就绪/阻塞队列

- 来源位置：操作系统 / 第二章 进程与线程
- 模块：进程与线程
- 核心内容：就绪队列保存只差 CPU 的进程；阻塞队列保存等待事件/资源的进程，事件到来后转入就绪。
- 易混点：就绪、运行、阻塞状态迁移；链表与循环队列选型。
- 典型错因：把“等待 CPU”和“等待事件”混为一谈。

### KP_0022 死锁条件与处理

## 计算机网络

### KP_0028 奈奎斯特与香农公式

- 来源位置：计算机网络 / 第二章物理层 / 通信基础
- 模块：物理层
- 核心内容：无噪声用奈奎斯特 2Wlog2V；有噪声用香农 Wlog2(1+S/N)。
