# 历史错题归档

本目录承接旧 Word/Markdown 整理包中已经结构化的历史错题，用于保存来源定位、旧整理信息和正式 ID 映射。

从 2026-05-12 起，历史归档题已进入统一正式错题库。`HDS/HCO/HOS/HCN` ID 只作为来源 ID 保留，正式复盘、关系边、专题链和知识点命中统一使用正式节点 ID。

## 文件说明

- `历史错题清单.md`：296 条历史错题的总清单。
- `按知识点索引.md`：按知识点键聚合历史错题；以后要找某个知识点的题，优先查这里。
- `按错因索引.md`：只把有明确错因描述的题按 E01-E10 归纳；错因不明确的题单独列为待复核。
- `按专题链索引.md`：按 LINK01-LINK07 汇总历史题，专题链命中仍需复核。
- `定位规则.md`：规定历史归档 ID、年份、定位标记、段落号、完整来源位置的区别和输出格式。
- `定位索引.md`：保存每条历史题在原资料中的定位标记、段落号和完整来源位置。
- `正式ID映射.md`：保存历史归档 ID 到统一正式节点 ID 的映射。
- `知识点补充归档.md`：37 条从旧笔记抽出的知识点补充。

## 历史归档 ID

- `HDS_0002`：数据结构历史题
- `HCO_0001`：计算机组成原理历史题
- `HOS_0001`：操作系统历史题
- `HCN_0001`：计算机网络历史题

历史归档 ID 只作为来源 ID 和定位入口，不等于正式错题节点 ID。

## 使用规则

1. 当用户要求某个知识点的错题时，先查统一正式 `知识点命中索引.md`，再用 `正式ID映射.md` 和 `定位索引.md` 补充来源定位。
2. 如果某题错因明确，可以参考 `按错因索引.md` 同步复习同类错因。
3. 如果某题只是命中知识点但错因不明确，也可以作为该知识点的复做题。
4. 如果某条历史题缺少可视化详情入口，先在正式节点中写“可视化详情入口待补充”。
5. 给用户输出历史题前，必须先读 `定位规则.md` 和 `定位索引.md`。
6. 给用户输出历史题时，必须同时输出历史归档 ID、年份、定位标记、段落号和完整来源位置。
7. 定位标记只指原资料内部题号或章节题号，例如 `5.1.4（06）`、`3.2.11（54）`、`2.3.33`。
8. 带括号题号是强定位标记，不带括号的三段式编号只能作为辅助定位标记。
9. 整理日期如 `2026.4.18`、真题年份如 `2016年真题`、知识点编号如 `CO03-14`、历史归档 ID 如 `HCO_0022` 都不算定位标记。
10. 如果定位标记未提取到，写“定位标记：未提取”，但仍然输出段落号和完整来源位置。
11. 本目录不保存完整题干、完整解析、图片和手写痕迹。
