## 主存与 CPU 连接：必须会说的机制

1. 按字节编址时，一个地址编号对应一个 Byte 存储单元；芯片规格中的位宽若不足一个字节，需要先做位扩展。
2. 位扩展改变每个地址单元能读写的位数，字扩展改变可寻址单元数量或连续地址段长度。
3. 芯片组覆盖的地址段长度由每组芯片的存储单元数决定；计算目标地址落在哪组时，先把段长度换成同一进制，再按连续段判断。
4. MAR 位数服务于整机可寻址地址空间，不由当前实际装机容量、单片芯片地址线或芯片片数直接决定。
5. 地址线数量决定可表示的地址编号范围；高地址区起点必须在合法地址空间内部，不能把越界地址当成起点。

### 主存连接类 Tutor 问法

- 看到“按字节编址 + 芯片规格”，你第一步判断什么：位宽、字数还是总 bit 数？
- 判断 MAR 位数时，为什么芯片片数和实际装机容量只是干扰条件？
- 给一个连续地址空间，如何说明某个地址落在哪个芯片组，不直接背旧题？
- 高地址区范围题中，为什么要先写合法地址上界再谈起点？

## DRAM 与存储器分类：必须会说的机制

1. DRAM 芯片的完整地址信息位数来自单片存储单元数；外部地址引脚数要考虑行地址、列地址分时复用。
2. 数据引脚由单片芯片位宽决定；片选线、芯片组数量属于整机扩展，不属于单片芯片自身的数据引脚。
3. ROM/Flash/BIOS 或 UEFI、OS 内核、主存运行位置要分层：固件负责早期启动和引导，OS 内核运行在可读写主存中。
4. DRAM/SDRAM 通电期间需要刷新；SRAM 用触发器保持状态，不需要周期性刷新；ROM/Flash 属于非易失存储，不靠周期刷新维持工作期数据。

### DRAM/分类类 Tutor 问法

- 题目问“单片 DRAM 芯片引脚数”时，为什么不能先算整个存储器需要多少片？
- 如何区分完整地址信息位数、物理地址引脚数、数据引脚数和片选线？
- 为什么“开机先执行固件”不等于“OS 本体存放或运行在 ROM/Flash 中”？

## Cache 地址划分：必须会说的机制

1. Cache 保存的是主存块的临时副本，对程序员透明。
2. Cache 命中、替换、装入由硬件及存储层次机制完成；不能把普通 Cache 块装入过程误说成由操作系统逐次参与。
3. 地址划分中，index 选择行或组，tag 保存地址高位用于匹配目标块，valid bit 只表示该行内容是否有效；tag 不是有效位。
4. Cache 不单独形成程序可见的地址空间；CPU 访存仍以主存地址空间为语义基础。

### Cache 类 Tutor 问法

- 为什么 tag 和 valid bit 必须分开解释？
- 直接映射、组相联中 index 各自定位什么对象？
- 为什么“主存一般用 DRAM”不能推出“全部主存陈述都天然正确”？
- Cache 对程序员透明具体意味着哪些动作不能归到应用或操作系统显式控制？

## 磁盘与 RAID：必须会说的机制

1. 机械磁盘随机访问一个扇区的平均时间通常拆为：平均寻道时间、平均旋转延迟、传输时间；若题设给控制器延迟，再单独加上。
2. 转速给出的是每分钟转数，先求单圈时间；平均旋转延迟取半圈时间，是随机等待目标扇区到达磁头下方的平均口径。
3. 磁盘扇区传输时间是磁头扫过目标扇区并读出数据的时间；如果给每磁道扇区数，可用单个扇区占一圈的比例求。
4. 计网发送时延看数据长度与链路带宽；磁盘扇区传输时间看转速、扇区数量或磁盘传输速率，不跨场景套公式。
5. RAID 的可靠性来自冗余或校验；条带化和 Cache 主要提升性能，不能直接当成可靠性保障。

### 磁盘/RAID 类 Tutor 问法

- 平均寻道时间和平均旋转延迟分别在等什么？
- 题目只给转速和每磁道扇区数时，怎样求单扇区传输时间？
- 什么时候磁盘平均访问时间需要加控制器延迟，什么时候不加？
- RAID 中哪些机制属于可靠性保障，哪些只改善吞吐或响应？

## 今日 Tutor 推荐检测顺序

1. 主存连接四连问：按字节编址、位/字扩展、MAR 位数、地址范围。
2. DRAM 单片引脚问法：完整地址信息位数、复用后的地址引脚、数据引脚、片选线。
3. Cache 透明性问法：tag/valid、index、硬件装入、主存地址空间。
4. 磁盘访问时间问法：三段公式、转速换算、扇区传输、控制器延迟。
5. RAID 目标分类问法：可靠性、性能、冗余、校验、条带化、Cache。
