# 状态转移与边界条件

## 定位

这是 408 Tutor 首批候选小专题，用于训练“先识别状态、再按事件逐步更新、最后判断边界”的主动回忆能力。它只保存概念机制和训练入口，不保存完整题干、完整解析、答案、错选项、图片或手写痕迹。

## 来源

- 专题链/LINK07 状态变化专题链.md
- 概念词典.md 中与拓扑排序、页面置换、缺页处理、进程状态、同步等待、PC 更新等相关条目
- 复习单元总表.md 中相关复习单元只作只读状态参考，不复制题目内容

## 核心能力

1. 识别状态对象：进程状态、页框状态、入度表、空闲分区链、标志位、TCP 状态或时间表。
2. 识别触发事件：I/O 完成、缺页、访问命中、输出顶点、分区回收、算术运算、连接建立或释放。
3. 逐步更新状态：每一步只改受影响字段，更新后再进入下一步。
4. 区分必然变化和可能变化：事件触发的状态转换不等于调度策略或最终结果。
5. 检查边界条件：空闲页框、存在位、访问位、修改位、入度为 0 集合、关键路径覆盖、无符号/有符号解释口径。

## 训练模块候选

| 模块 | 主动回忆问题方向 | 保护边界 |
|---|---|---|
| 进程状态转换 | 事件发生后从哪个状态到哪个状态；哪些变化是必然，哪些依赖调度 | 不使用具体真题选项 |
| 页面置换状态表 | 缺页、置换、命中后状态字段如何更新 | 不给原访问序列答案 |
| 拓扑排序入度更新 | 初始入度表、当前 0 入度集合、删除顶点后的更新 | 不复制原题图 |
| AOE/关键路径时间表 | ve/vl 与边活动 e/l 的角色边界 | 不复制原网络图 |
| 动态分区空闲链 | 回收、合并、按算法重排的顺序 | 不复制原分区表 |
| CF/OF 标志位 | 同一位串如何按无符号和有符号口径解释 | 不给具体选项答案 |
| TCP 状态变化 | 连接建立、释放和拥塞窗口的状态推进 | 不复制完整报文题 |

## Tutor 输入建议

StudyVault 输入只保留：

- 概念定义。
- 状态变量列表。
- 事件到状态变化的规则。
- 易混边界。
- 口头自测题干，不含原题答案和选项。

不进入 Tutor 输入：

- 正式错题完整题干。
- 标准答案、正确选项、错选项。
- 历史来源中含答案的完整路径片段。
- 图片、手写痕迹、长解析。

# 错因模式总览

本页是 E01-E10 错因标签的 wiki 层总览，用于后续沉淀“为什么反复错”和“如何防错”。它不替代 错因标签表，也不自动回写正式节点。

## 当前用途

- 帮助 query 时从错因模式召回相关概念和专题。
- 帮助 ingest 时判断 GPT 给出的错因是否只是候选。
- 帮助 lint 时检查是否把知识点命中误写成错因。

# 关系网状态摘要

本页总结正式关系网对 wiki 层的可用性。它不复制 关系边表，不新增关系边，只记录 Dashboard 和 query 可使用的高层状态。

- 正式节点、关系边、专题链、复做记录和复习单元仍由 408 原规则维护。
- LAMBIC 层已经能读取正式表作为 source，但不能绕过正式入库流程。
