## 主要漏洞

这次不是单个错题暴露的问题，而是 OS 大纲层级遗忘：知道一些名词，但需要先重新建立“应用程序 - 操作系统内核 - 硬件协作”的总框架。

当前优先稳住四条主线：

1. OS 是资源管理者 + 服务提供者。
2. CPU 对应进程管理和调度，内存对应地址转换和虚拟内存，外存对应文件管理，设备对应 I/O 管理。
3. 用户程序不能直接操作硬件，通常通过系统调用进入内核；中断 / 异常是 CPU 转向内核的重要触发机制。
4. 复习每个 OS 知识点时先问：它管的是什么资源，发生在用户态还是核心态，有没有状态变化、地址转换或资源竞争。

### 关键纠正

1. **MIPS / CPI / IPC**：MIPS = 每秒百万条指令（带“秒”量纲）；CPI = 每条指令的时钟周期数（无秒量纲，是纯比值）；IPC = 1/CPI。看英文首字母：第二个字母是分母、第一个字母是分子（`I`nstructions `P`er `C`ycle = I/C；`C`ycles `P`er `I`nstruction = C/I）。
2. **B 树 vs B+ 树关键字角色**：B 树关键字“夹在孩子之间”做**分隔点**，n 个关键字切出 n+1 段 → 孩子 = 关键字 + 1；B+ 树关键字“贴在孩子头上”做**索引值**，每个孩子配一个索引 → 孩子 = 关键字。
3. **GHz↔ns 对偶**：单位对偶比记次方快。`f = 1 GHz → T = 1 ns`、`f = 100 MHz → T = 10 ns`、`f = 1 MHz → T = 1 μs`、`f = 2 GHz → T = 0.5 ns`。
4. **管程 ≠ 管态**：管程 (monitor) 是并发同步机制，封装共享变量 + 操作 + 条件变量；管态 = 核心态 = 内核态，是 CPU 运行状态。只差一字但完全不同概念。
5. **原语归类**：原语本身运行在核心态、不可中断，不由用户态代码直接发起；不要把它和库函数并列归为“用户主动发起”。
6. **特权指令在用户态**：编译/汇编**能过**（汇编器只翻译助记符不做权限校验），但**执行时**会触发非法指令异常并陷入内核。“能写出来”和“能执行成功”是两件事。
