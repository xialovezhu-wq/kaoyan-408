## 1. 先序、中序、后序：不能唯一建树，不等于不能判断局部关系

触发节点：`DS_2011_002`、`DS_2012_001`、`DS_2015_001`

今天这组树题集中暴露的是：你容易把“遍历序列不能唯一确定整棵树”扩大成“什么结构关系都不能判断”。

`DS_2011_002` 今天做对了，说明你已经能接受：

```text
中序里根在边界 = 某一侧子树为空
```

这点很好，说明“中序根位置决定左右子树范围”已经开始稳定。

但 `DS_2012_001` 又错在另一个边界：前序和后序虽然不能唯一建树，但可以判断祖先关系。

关键规则：

```text
若 x 在前序中早于 y，
且 x 在后序中晚于 y，
则 x 是 y 的祖先。
```

为什么：

```text
前序：祖先先遇到，后代后遇到
后序：后代先结束，祖先后结束
```

所以以后看到“前序 + 后序”题，不要直接说“不能唯一建树，所以不能判断”。先问：

```text
能不能判断根？
能不能判断祖先？
能不能判断某些局部父子或子树范围？
```

`DS_2015_001` 的断点是：你今天终于把“先序固定”理解成了“第一次遇到结点的顺序固定”，可以模拟成固定入栈顺序；中序是“左子树结束后访问自己”，可以模拟成合法出栈顺序。

这道题下次只记一句：

```text
先序固定 = 入栈顺序固定；
中序变化 = 出栈时机变化；
不同树形数 = 合法出栈序列数 = 卡特兰数。
```

## 2. 树转二叉树：分支结点贡献的是最后孩子，不是它自己

触发节点：`DS_2011_003`

今天这题又错，说明你已经知道“右孩子 = 下一个兄弟”，但计数语义还没彻底稳。

树转二叉树使用孩子兄弟表示法：

```text
左孩子 = 第一个孩子
右孩子 = 下一个兄弟
```

所以“无右孩子”表示：

```text
没有下一个兄弟
```

分支结点数的贡献方式是：

```text
每个分支结点作为父亲，贡献它孩子序列中的最后一个孩子。
```

这不是在数“这个分支结点自己有没有右孩子”。根结点不是任何人的孩子，所以不会被“每个父亲的最后一个孩子”统计到；但根本身没有兄弟，因此根也无右孩子，要额外算。

防错句：

```text
分支结点数数的是父亲数量；
父亲贡献的是最后孩子；
根不是任何人的孩子，所以根要额外看。
```

## 3. 表达式 DAG：合并完整重复子表达式，不是合并同名运算符

触发节点：`DS_2019_001`

今天你对这题的提炼很有用：做表达式 DAG 题不必真的画很复杂的图，先数“不同变量 + 不同子表达式”通常更快。

但规则要严谨：

```text
能合并的是完整重复子表达式。
不能只因为运算符相同就合并。
```

例如：

```text
x + y 和 x + y 可以合并
x + y 和 x + z 不能合并
x / y 和 y / x 不能合并
```

做题流程固定成三步：

```text
1. 先拆表达式，明确每个运算的输入。
2. 找完整重复子表达式。
3. 数不同变量结点 + 不同运算子表达式结点。
```

防错句：

```text
DAG 共享的是相同结果，不是相同符号。
```

## 4. 图算法：Kruskal、Prim、BFS 分别优化不同东西

触发节点：`DS_2020_002`、`DS_2023_003`

今天图算法最重要的收获是：不要看见“最小、最短、权值都小”就混成一个问题。

三种算法目标完全不同：

```text
Kruskal：全图边权递增选边，不成环就加入，目标是 MST 总边权最小。
Prim：从当前点集向外扩张，目标也是 MST 总边权最小。
BFS：按层扩展，边权全为 1 时可求源点到各点的最短路径。
```

`DS_2020_002` 错在把 Kruskal 做成 Prim：

```text
Kruskal 不问“当前树往外哪条边最短”。
Kruskal 先看全图所有边的权值顺序。
```

Kruskal 每一步只问：

```text
这条边的两个端点是否已经在同一个连通分量？
同一个分量：加了成环，跳过。
不同分量：加入，合并分量。
```

`DS_2023_003` 错在把最小生成树当成最短路径树：

```text
MST 只保证整棵树总边权最小；
不保证从某个源点到每个顶点的路径最短。
```

边权全为 1 时，最短路径就是边数最少。BFS 一层一层扩展：

```text
第 0 层：源点
第 1 层：一步能到的点
第 2 层：两步能到的点
```

所以第一次到达某点时，就是边数最少。

防错句：

```text
MST 看整棵树的总边权；
最短路径看源点到每个点的路径长度。
```

## 5. 简单路径：顶点不重复

触发记录：`DS06-01 图的基本概念`

今天你复习了简单路径，这是一个很基础但容易模糊的定义。

路径先要求：

```text
相邻顶点之间有边。
```

简单路径再要求：

```text
路径中的顶点不重复。
```

简单回路则允许：

```text
首尾顶点相同，但中间顶点不重复。
```

防错句：

```text
简单路径看顶点是否重复；
简单回路允许首尾相同。
```

## 6. 查找基础：顺序查找通用，折半查找条件严格

触发记录：`DS07-02`、`DS07-03`、`DS07-04`

今天你补了查找基础，这块先稳住三句话：

```text
查找：在表中确定给定关键字是否存在。
ASL：关键字比较次数的期望。
查找题重点看比较次数。
```

顺序查找：

```text
从一端开始逐个比较。
不要求表有序。
顺序表、链表都可用。
等概率成功查找 ASL = (n + 1) / 2。
时间复杂度 O(n)。
```

折半查找：

```text
每次比较中间元素，一次排除一半。
必须有序。
通常要求顺序存储，因为要能随机访问中间元素。
时间复杂度 O(log n)。
```

折半查找判定树要记：

```text
结点所在层数 = 成功查找时的比较次数。
```

防错句：

```text
有序链表也不适合折半查找；
查找位置快，不代表插入删除整体也快。
```

## 今天最后只背这 8 句

1. 前序早、后序晚，可以判断祖先关系。
2. 先序固定像入栈固定，中序变化像出栈时机变化。
3. 树转二叉树中，分支结点贡献最后孩子，根要单独看。
4. DAG 合并完整重复子表达式，不合并单纯相同运算符。
5. Kruskal 看全图边权排序和连通分量，不看当前树向外扩张。
6. MST 看整棵树总代价，最短路径看源点到各点路径长度。
7. 简单路径顶点不重复，简单回路允许首尾相同。
8. 顺序查找通用 O(n)，折半查找要求有序顺序表 O(log n)。
