### AOV / AOE / 关键路径

这是今天最明显的初始漏洞。AOV 网是顶点表示活动、边表示先后关系；AOE 网是边表示活动、顶点表示事件、边权表示持续时间。ve 是事件最早发生时间，不是活动最晚开始时间。追问后能说明：求 ve 对所有前驱取 max，因为事件必须等全部前驱活动完成，谁慢等谁；求 vl 从后继反推取 min，因为所有后继给出上界，必须满足最紧的上界。该点从未通过调整为基本通过，仍需用一个小网做过程题确认。

### 表达式 DAG

能抓住“完整重复子表达式才可合并”。追问后能说明 a-b 与 b-a 不能合并，因为减法不满足交换，左右操作数顺序不同，表示的完整子表达式不同。该点本轮通过。

### 散列表查找失败 ASL

今天补充复习了散列表查找失败 ASL。核心边界是：失败 ASL 不是平均多久找到已有元素，而是平均多久确认 key 不存在。开放定址法要从每个可能散列入口开始，按探测序列查到空单元或失败标志；链地址法要查完对应桶。失败 ASL 的分母按散列函数可能入口数 r，不按已有元素个数 n。

**第二轮自测已通过。** 分母 = 散列函数值域个数（即模值 m），不是物理表长；物理表长可以比 m 更大。成功 ASL 分母 = 关键字个数 n。概念边界今日已清晰，7 天后轻量确认。

### 开放定址法删除标记

由 DS_2023_005 暴露。核心规则：线性探测散列表中，删除关键字后不能直接将该位置置为"空"，必须保留一个"已删除"标记。原因：如果某关键字 B 在插入时因位置 p 被占而探测到 p+1，删除 p 处关键字后若置空，则查找 B 时探测到 p 发现"空"便提前宣告失败，错误地认为 B 不存在。探测遇到"删除标记"必须继续，遇到真正空位才宣告失败。今日自测通过，7 天后轻量确认。

### CPU 速度提高 vs 执行时间减少

由 CO_2012_002 暴露。核心换算：速度提高到原来的 k 倍 → CPU 时间变为原来的 1/k，不是减少 k%。速度提高 50% = 速度 × 1.5 → 时间 = 原时间 ÷ 1.5 = 原时间 × 2/3，减少 1/3，不是减少 1/2。同时注意：CPU 提速只影响 CPU 时间，I/O 时间不变；总运行时间 = CPU 时间 + I/O 时间，两部分要分开算。今日自测通过，7 天后轻量确认。

### 机器字长与各类寄存器宽度对应关系

由 CO_2020_001 暴露。对应规则：

- ALU 运算位数 = 机器字长（ALU 处理一个字长的整数）
- 通用寄存器位数 = 机器字长
- IR（指令寄存器）位数 = 指令字长（不一定等于机器字长）
- 浮点寄存器位数 = 浮点数格式位数（IEEE 754 单精度 32 位、双精度 64 位），可大于机器字长
- PC（程序计数器）位数 = 地址总线宽度（由主存地址空间大小决定，不由机器字长决定）
- MAR 位数 = 地址总线宽度，与 PC 同理
- MDR 位数 = 存储字长（内存一次读写的位数，通常等于机器字长，但决定因素是存储字长）

今日自测：ALU / 通用寄存器 / IR / 浮点寄存器结论全对；PC 是今日新学点，MAR/MDR 各自的决定因素也是今日新学。**3 天后回滚，重点追问 PC / MAR / MDR 各自由什么决定。**

### CO01 性能指标计算链

今天后半段连续入库了 `CO_2010_001`、`CO_2012_002`、`CO_2013_003`、`CO_2021_001`、`CO_2022_003`，共同暴露的是同一组性能指标边界不稳：

- `CO_2010_001`：遗漏“提高 CPU 时钟频率会缩短时钟周期”，没有把主频接到 `CPU 执行时间 = IC * CPI * T = IC * CPI / f`。
- `CO_2012_002`：把“速度提高 50%”误当成“时间减少 50%”，没有先转成速度变为 1.5 倍、时间除以 1.5。
- `CO_2013_003`：不会把指令比例和各类 CPI 加权成平均 CPI，也不清楚 MIPS 的含义。
- `CO_2021_001`：忘记 `1 PFLOPS = 10^15 FLOPS`，把科学计数法和“亿亿”数量级换错。
- `CO_2022_003`：平均 CPI 会算，但把 `1GHz` 下的 `ns/us/ms` 换算错，把微秒误看成毫秒。

今天对这个单元的判断：不是单个公式不会，而是“性能指标单位、比例、时间口径”没有形成一条稳定链。明天回滚时先闭卷写：

1. `CPU 执行时间 = 指令条数 * CPI * 时钟周期 = 指令条数 * CPI / 主频`
2. `平均 CPI = Σ(指令比例 * 该类 CPI)`
3. `总周期数 = 指令条数 * 平均 CPI`
4. `1GHz = 10^9Hz`，所以 `1GHz` 下 1 周期 = `1ns`
5. `1ns = 10^-9s`，`1us = 10^-6s`，`1ms = 10^-3s`
6. `MIPS` 是每秒百万条指令，`FLOPS` 是每秒浮点操作次数，`PFLOPS = 10^15 FLOPS`

这个单元已记录为 `RU_CO01_09_16`，错误次数累计到 5。下次复习不要只背结果，要从“指令比例 -> 平均 CPI -> 总周期数 -> 主频换算 -> 时间单位”完整走一遍。
