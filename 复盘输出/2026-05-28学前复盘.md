## 主要漏洞

### CO01 性能指标计算链

主线公式、加权平均 CPI、速度 / 时间换算今天都立住了。昨天最痛的「速度提高 25% → 时间减少 20%」今天能闭卷推出来，这条线**算正式打通了**。

但是 MIPS 升级题再次栽在**数量级**上：把 3 GHz = 3×10^9 Hz 写成 3×10^8，导致 750 MIPS 算成 75 MIPS，而且没有用「升级后不能变慢」的常识反向校验。这和昨天的「ns/μs/ms 换错」「PFLOPS 数量级错位」是同一种病。

MIPS 概念也要重新立：

```
MIPS = 每秒百万条指令 = 主频(Hz) / (CPI × 10^6)
IPC  = 每周期指令数   = 1 / CPI       （这才是和 CPI 倒数关系的量）
```

不要再把 MIPS 描述成「一个周期能执行多少条指令」——那是 IPC。MIPS 的「M」是 Million，必须带「每秒百万」。

### B+ 树关键字数 = 孩子数

今天最锋利的漏洞。讲完区别后追问 5 阶 B+ 树非根非叶索引结点最少几个关键字，我用了「⌈5/2⌉ − 1 = 2」——这是 B 树公式，不是 B+ 树。

**408 主流（王道 / 严蔚敏）口径下，m 阶 B+ 树非根非叶索引结点**：

```
孩子数 n   ∈ [⌈m/2⌉, m]      5 阶 → [3, 5]
关键字数 k = n                5 阶 → [3, 5]
```

口诀：

```
B 树：  关键字 = 孩子 − 1     关键字是分隔点
B+ 树： 关键字 = 孩子          关键字是索引值
```

另外要明确：B+ 树**只有叶子层**用按关键字顺序的指针串联（为区间查询），非叶（索引）结点之间不串联。

### AOE 网 ve / vl 与关键路径

今天 AOE 这条线打通了。从复盘起点的「模糊」直接升到「通过」，整套过程题（V1→V2→V4 / V1→V3→V4 两条关键路径的 4 顶点小网）的 ve、vl、关键活动、关键路径全对。

完整递推（已经稳定）：

```
ve(源) = 0
ve(k) = max{ ve(j) + dut(<j,k>) | <j,k> 是 k 的入边 }
      事件必须等所有入边活动完成，谁慢等谁 → max

vl(汇) = ve(汇)
vl(k) = min{ vl(j) − dut(<k,j>) | <k,j> 是 k 的出边 }
      每条出边给一个上界，必须满足最紧的 → min

e(<i,j>) = ve(i)
l(<i,j>) = vl(j) − dut(<i,j>)
关键活动：e = l
```

唯一术语小毛病：把「事件最晚发生时间 vl」说成了「最晚开始时间」（最晚开始时间是活动 l，不是事件 vl）。事件 vs 活动的用词下次要分清。

### PC / MAR / MDR / IR 位数决定因素

概念分类今天补上了，记住的版本：

| 寄存器 | 位数决定因素 | 关键理由 |
|---|---|---|
| PC | 主存地址位数 | 装的是地址 |
| MAR | 主存地址位数 | 同 PC |
| MDR | 存储字长 | 主存一次读写多少位就要多少位 |
| IR | 指令字长 | 装的是指令编码本身 |
| 通用寄存器 | 机器字长 | 整数运算通路 |
| ALU | 机器字长 | 同上 |
| 浮点寄存器 | 浮点格式位数 | IEEE 754 单 32 / 双 64 |

一句话区分：**机器字长只决定整数运算通路**；地址类（PC/MAR）盯地址空间；数据类（MDR）盯存储字长；指令类（IR）盯指令字长；浮点类盯浮点格式。

### 二进制容量换算（今日最大的共性漏洞）

追问 4 暴露：「4 GB = 4 × 10³ B」。**这是二进制单位被当成了十进制**。如果按这个算，4 GB 只有 4000 字节，地址 12 位，整道题报废。

**容量类换算（2 的次方制）**：

```
1 KB = 2^10 B  ≈ 10^3 B
1 MB = 2^20 B  ≈ 10^6 B
1 GB = 2^30 B  ≈ 10^9 B
1 TB = 2^40 B
1 PB = 2^50 B

4 GB  = 2^32 B       8 GB  = 2^33 B       16 GB = 2^34 B
2 GB  = 2^31 B      512 MB = 2^29 B      128 MB = 2^27 B
```

**频率 / 速度类换算（10 的次方制）**：

```
1 GHz = 10^9 Hz      1 周期 = 1 ns
1 MHz = 10^6 Hz      1 周期 = 1 μs
1 kHz = 10^3 Hz      1 周期 = 1 ms

1 ns = 10^-9 s     1 μs = 10^-6 s     1 ms = 10^-3 s

1 MIPS = 10^6 条/秒
1 GFLOPS = 10^9    1 TFLOPS = 10^12   1 PFLOPS = 10^15   1 EFLOPS = 10^18
```

**核心区分**：

```
容量 / 地址空间   → 2 的次方制（KMGT 之间是 ×2^10）
频率 / 时间 / 操作次数 → 10 的次方制（KMGT 之间是 ×10^3）
```

「4 GB 内存」= 2^32 B；「2 GHz 主频」= 2 × 10^9 Hz。两套不能混。
