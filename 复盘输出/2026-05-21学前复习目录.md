## 一、开始新课前必过：D1 回滚

这部分来自 2026-05-20 新登记的 3 个复习单元，今天是 D1 回滚。先用 20 分钟过完。

### 1. DFS 首次访问序列与回溯语义

- 复习单元：`RU_DS_2015_002`
- 触发节点：`DS_2015_002`
- 先看什么：DFS 序列记录的是“第一次访问顺序”，不是一条连续路径。
- 必须说清：
  - 什么时候沿边继续深入。
  - 什么时候回溯。
  - 回溯后为什么可以从祖先结点继续访问别的分支。
- 防错句：DFS 序列不是路径，相邻访问点之间可能发生回溯。

### 2. 拓扑排序序列生成规则

- 复习单元：`RU_DS06_20`
- 触发节点：`DS_2012_003`
- 先看什么：拓扑排序处理的是有向无环图中的先后约束，不是 DFS/BFS 遍历。
- 必须说清：
  - 每条边 `u -> v` 只要求 `u` 在 `v` 前面。
  - 每一步都要重新找当前入度为 0 的顶点。
  - 删除顶点后要同步更新后继入度。
  - 图不连通或有孤立点，不影响拓扑排序存在性。
- 防错句：拓扑排序先问有没有有向环，不问图连不连通。

### 3. 最小生成树 vs 哈夫曼树

- 复习单元：`RU_DS05_18_DS06_14`
- 触发节点：`DS_2012_002`
- 先看什么：最小生成树是在图里选边，哈夫曼树是在权值集合里合并结点。
- 必须说清：
  - Prim 和 Kruskal 的对象是带权无向连通图中的边。
  - 哈夫曼树每次合并两个最小权值结点，目标是 WPL 最小。
  - MST 的总代价唯一，但树形不一定唯一。
- 防错句：看到图、边、连通、无回路，想 MST；看到两个最小权值结点合并，想哈夫曼树。

## 二、今天新学前的旧薄弱铺垫

这部分不用做成大复盘，只要按目录快速预习，保证后面学新内容时不会被旧概念卡住。

### 1. 树与二叉树：数量语义

关联节点：`DS_2009_001`、`DS_2010_001`、`DS_2016_002`

先复习：

```text
树的度数总和 -> 边数 -> 总结点数 -> 叶结点数
完全二叉树层序填充 -> 叶结点只能在最后两层
森林中边数 -> 非根结点数 -> 树的棵数
```

学前检查：

- 度数和为什么是边数，不是叶结点数？
- 完全二叉树某层有叶结点，为什么不能直接推出树高固定？
- 森林中为什么“总结点数 - 边数”就是树的棵数？

### 2. 树、森林与二叉树转换

关联节点：`DS_2011_003`

先复习：

```text
左指针 = 第一个孩子
右指针 = 下一个兄弟
无左孩子 = 原树中没有孩子
无右孩子 = 原树中没有下一个兄弟
```

学前检查：

- 看到“树对应的二叉树”时，能不能先切换到孩子兄弟表示法？
- 题目问“无右孩子”时，你数的是叶结点，还是没有下一个兄弟的结点？

### 3. 遍历序列与线索二叉树

关联节点：`DS_2011_002`、`DS_2012_001`、`DS_2014_003`、`DS_2015_001`、`DS_2024_001`

先复习：

```text
先序：根左右
中序：左根右
后序：左右根
中序相邻结点 -> 前驱 / 当前 / 后继
只给先序或先序+后序时，不要默认能唯一建树
```

学前检查：

- 根在中序序列首位时，表示什么结构？
- 中序序列中相邻结点为什么可以直接转成前驱/后继关系？
- “不能唯一建树”为什么不等于“什么局部关系都不能判断”？

### 4. 图的数量与连通边界

关联节点：`DS_2010_002`、`DS_2017_001`

先复习：

```text
可能连通 -> 生成树 -> n - 1 条边
必然连通 -> 最大不连通图 + 1
无向图度数和 = 2|E|
```

学前检查：

- 题目问“存在一种情况”还是“任何情况下保证”？
- 最大不连通无向图为什么是 `K(n-1) + 1 个孤立点`？
- 有边数时，为什么要先算全图总度数 `2|E|`？

### 5. AOV 网、AOE 网与关键路径

关联节点：`DS_2013_001`

先复习：

```text
AOV：点是活动，边是先后关系，常用于拓扑排序
AOE：点是事件，边是活动，权是时间，常用于关键路径
ve：所有前驱完成后的最早发生时间，所以取最大值
关键路径：源点到汇点的最长活动链
```

学前检查：

- AOE 网中，为什么 `ve` 不是取最短到达时间？
- 关键事件和关键路径有什么区别？
- 多条关键路径同时存在时，为什么只缩短一条不一定缩短总工期？

## 五、今天学习时的防错总句

```text
先判断对象，再判断约束。

对象可能是：
树 / 森林 / 二叉树 / 转换后的二叉树 / 无向图 / 有向图 / AOV / AOE。

约束可能是：
数量关系 / 访问顺序 / 先后顺序 / 连通保证 / 选边最优 / 最长活动链。
```

今天新学时，只要题目一出现“序列、连通、路径、生成树、关键、唯一、保证”这些词，先停一下，把它归到上面的对象和约束里，再继续做。
