## 今晚问答复盘 · 已巩固（答对、立住）

1. **移动次数与初态**：与初态无关的是**基数排序**（每趟分配+收集各搬 n 次、共 d 趟 = n×d，只由 n、d 决定）；直接插入 / 冒泡 / 快排等比较类随初态变。简单选择**比较次数固定 n(n−1)/2**、但**交换次数 ≤ n−1 且随初态变**——"比较固定 ⇏ 移动与初态无关"。
2. **反判排序**：直接插入 = 前缀有序 + **后缀保持原序（未动）**；二路归并 = 第 k 趟段长 2^k、**从头按固定长度切、段内有序、段间未必**。命门：首段 {11,12,13,7} 长 4 却**段内无序 → 排除归并**；孤立递增片段（如 {7,8,9,23}）**不算"段"**，不能当归并证据。
3. **顺序→链式存储**：尺子 = **是否强依赖下标随机访问**。顺序扫描型（直接插入 / 简单选择 / 冒泡）渐进**不降阶**；**希尔**（按增量 d 跳跃访问）、**堆**（父子下标 2i/2i+1/⌊i/2⌋）受影响。注意问的是**渐进阶**，链式下直接插入虽能改指针省移动，但仍 O(n²)。
4. **学前三老坑零反弹**：补虚段 `u=(n−1) mod (k−1)`，u=0 不补 / 否则补 (k−1)−u；建堆从 ⌊n/2⌋ **向下**调整、删顶**向下**、插入**向上**；基数 **LSD**（最高位主导 → 必须最后排 → 从最低位起）。

## 今晚新暴露 / 待补强（重点回滚）

### 1. 冒泡排序"指纹"说错（今晚新错点）
- 当时怎么错：把冒泡某趟特征说成"没有逆序对"。
- 正确怎么想："没有逆序对" = **整体已排好序**的标志，不是某一趟指纹。冒泡第 k 趟后 = **k 个最大值已沉到末尾 k 位（或 k 个最小浮到开头）且在最终位置**。冒泡 vs 选择都"一端 k 个就位"，区别看**未排序区**：选择基本维持原序、冒泡被相邻交换搅动。
- 回滚：配 DS_2009_003 / RU_DS08_QUICK_MERGE，下次抽时连冒泡 / 选择指纹一并确认。

### 2. 直接插入 vs 快排选型漏 2 个维度
- 当时怎么错：只说了稳定性 / 空间 / 时间三维度，漏掉"基本有序""小规模"。
- 正确怎么想：选型**四维度 = 基本有序、小规模、稳定性、严格辅助空间**。基本有序时直接插入 ≈ O(n)，而快排**固定枢轴遇基本有序 / 逆序反而退化**；小规模时直接插入常数小更优。
- 回滚：RU_DS08_CHOOSE / DS_2022_002（掌握 3），下次确认四维度齐全。

### 3. 快排递归次数判据没答全
- 当时怎么错：解释了退化机制（固定取首元素 + 有序/逆序 → 单支树 → O(n²)），但没答"递归次数由什么决定"。
- 正确怎么想：递归次数 / 深度取决于**划分的平衡性**（= 初始排列 + 枢轴选择），**与处理左右子区间的先后顺序无关**。pivot 每趟归位 ≠ 递归次数固定。
- 回滚：配 DS_2010_003 / RU_DS08_QUICK_MERGE，下次一句确认。
