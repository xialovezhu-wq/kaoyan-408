## 1. 树的数量账本：度数总和不是叶结点数

为什么复盘：

`DS_2010_001` 暴露的问题是：你能把非叶结点发出的孩子数加起来，但没有先判断这个和表示什么，直接把“度数总和 / 孩子总数”当成了叶结点数。

当时怎么错：

你算出了一个中间量，但跳过了语义确认。这个中间量其实表示边数，不表示叶结点数。

正确应该这样想：

```text
结点的度 = 这个结点的孩子数
所有结点的度数总和 = 树中的边数
一棵树的边数 = 总结点数 - 1
叶结点数 = 总结点数 - 非叶结点数
```

所以路线应该是：

```text
度数总和 -> 边数 -> 总结点数 -> 叶结点数
```

不能走成：

```text
度数总和 -> 叶结点数
```

防错提醒：

```text
度数和是边，不是叶。
叶结点要从总结点里减非叶。
```

## 2. 树、森林转二叉树：先翻译左右指针含义

为什么复盘：

`DS_2011_003` 暴露的问题是：看到“树对应的二叉树”后，没有先切换到孩子兄弟表示法，导致无法正确理解“无右孩子”到底在数什么。

当时怎么错：

你把转换后的二叉树当普通二叉树直接看，没有先把左右指针还原成原树中的关系。

正确应该这样想：

树或森林转二叉树时，使用孩子兄弟表示法：

```text
左指针 = 第一个孩子
右指针 = 下一个兄弟
```

因此：

```text
无左孩子 = 原树中没有孩子
无右孩子 = 原树中没有下一个兄弟
```

如果题目问转换后二叉树中“无右孩子”的结点，就不是在问原树叶结点，而是在问哪些结点没有下一个兄弟。根结点没有兄弟，也要单独纳入结构语义判断。

防错提醒：

```text
转换题先翻译指针。
左看孩子，右看兄弟。
无右孩子 = 无下一个兄弟。
```

## 3. 图的连通性：可能连通和必然连通不是一个题型

为什么复盘：

`DS_2010_002` 暴露的问题是：把“任何情况下都连通”误读成“存在一种连通构造”，于是直接套用了生成树的 `n - 1` 条边。

当时怎么错：

你识别到了“连通”，但没有继续区分题目是在问“可以连通”还是“保证连通”。

正确应该这样想：

如果问“存在一种连法使图连通”，这是可能连通：

```text
n 个顶点的无向连通图最少边数 = n - 1
```

如果问“任何情况下都连通”或“保证连通”，这是必然连通。不能直接用生成树，要先想最大不连通图：

```text
n 个顶点的最大不连通无向图 = K(n-1) + 1 个孤立点
最大不连通边数 = C(n-1, 2)
必然连通最少边数 = C(n-1, 2) + 1
```

防错提醒：

```text
存在连通，看生成树。
保证连通，看最大不连通再加一。
```

## 4. 无向图度数账本：每条边贡献两个端点度数

为什么复盘：

`DS_2017_001` 暴露的问题是：你只统计了题目中明确给出的顶点数量，没有用无向图握手定理检查全图总度数，也没有把“其他顶点”的度数限制当成补足剩余度数的条件。

当时怎么错：

你把已知顶点当成了全图，而题目其实还要求根据边数和度数限制反推出至少还需要多少未知顶点。

正确应该这样想：

无向图的基本账本是：

```text
所有顶点度数之和 = 2|E|
```

做这类题时，步骤是：

```text
1. 用边数算出全图总度数 2|E|
2. 扣掉已知顶点贡献的度数
3. 得到剩余度数
4. 根据“其他顶点”的最大允许度数，判断至少需要多少个顶点补足
```

如果题目说“其他顶点的度均小于 3”，意思不是这些顶点可以忽略，而是每个其他顶点最多只能贡献 2 个度。

防错提醒：

```text
无向图先算总度数 2E。
其他顶点不是空气，是补足剩余度数的变量。
```

## 5. 这两天真正暴露的共同问题

这几道题表面上分别属于树、树转二叉树和图，但底层问题一致：

```text
算出一个量以后，没有先确认这个量的结构含义。
看到一个关键词以后，没有继续检查限定词。
```

后面遇到数据结构数量关系题，先问三句话：

```text
1. 当前结构是什么：树、森林、二叉树、转换后的二叉树，还是无向图？
2. 我算出来的量到底在数什么：边、根、叶、孩子、顶点，还是度数？
3. 题目问的是存在一种情况，还是任何情况下都成立？
```
