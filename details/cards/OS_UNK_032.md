> [!answer]- 解析
>
> 我的误选：C（1，2）  
> 正确答案：B（1，0）
> 
> 核心结论（资源型信号量）  
> - `K > 0`：可用资源数 `M = K`，等待数 `N = 0`  
> - `K = 0`：`M = 0`，`N = 0`  
> - `K < 0`：`M = 0`，`N = |K|`  
> > 速记：`M = max(K, 0)`；`N = max(-K, 0)`
> 
> 本题代入  
> - 当前 `K = 1 (>0)` ⇒ `M = 1`，`N = 0`
> 
> 易错点  
> - 将“当前值为 1”误解为“已占用 2 且仍有 2 在等”，忽视了只要 K>0，就不存在等待。
