> ### 正确答案
> B. 数据总线线数
> 
> ### 解析
> - **n 位 CPU** → n 表示 **一次能并行处理/传输的数据位数**。  
> - 即 CPU 内部数据通路宽度、数据总线宽度。  
> - 与 CPU 地址总线无关，地址总线决定寻址范围。  
> 
> ### 总结
> n 位 CPU → n = 数据总线宽度 = 一次能处理的二进制位数。
