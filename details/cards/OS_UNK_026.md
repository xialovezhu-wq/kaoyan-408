> ### 我的错误选择
> - 我选了 B. S.value <= 0  
> - 错因：混淆了执行 P 操作前后的条件，没注意题目强调的是 “执行 P 操作后” 的情况。
> 
> ---
> 
> ### 正确答案
> - A. S.value < 0
> 
> 原因解析  
> - 信号量 S 的含义：  
>   - S.value > 0 ：表示系统中当前可用资源的数量。  
>   - S.value = 0 ：表示刚好没有空闲资源，但也没有等待的进程。  
>   - S.value < 0 ：表示资源已经没有了，并且有进程在等待队列中，|S.value| 代表等待的进程数。  
> - P 操作逻辑：  
>   - 执行 P(S) ：S.value--；  
>   - 如果 S.value < 0 → 当前进程进入等待队列。  
> - 所以，只有在 执行 P 操作后 S.value < 0 时，进程才会阻塞。
> 
> ---
> 
> ### 总结记忆
> - P 操作：S.value--；若 < 0 → 阻塞  
> - V 操作：S.value++；若 <= 0 → 唤醒一个等待进程  
> - 考题陷阱：一定要分清楚题目问的是 P/V 执行前 还是 执行后 的条件。
